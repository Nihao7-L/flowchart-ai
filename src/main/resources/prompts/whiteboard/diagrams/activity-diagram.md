活动图 = 带**并发**表达能力的流程：可以有分叉（同时做）与汇合（都做完才继续）。

- **必须声明 `diagramType:"activity-diagram"`**。
- 动作是矩形（圆角意象），判断是菱形；起点一个实心意象的椭圆、终点一个。
- **分叉 / 汇合用一根粗横杠表达**：没有横杠类型时，建一个名为「分叉」/「汇合」的矩形节点充当横杠 —— 一个入边多条出边 = 分叉，多条入边一个出边 = 汇合。分叉后必须能汇合，不能只分不合。
- 分叉出来的并行分支各自用 `group` 命名（如「并行：校验」），让它们各自成组、不会与主链混排。
- 判断菱形每条出边写清守卫条件（「库存充足」「库存不足」）。
- 与流程图的区别就在这：凡是「同时进行」「都完成才继续」的需求走活动图，纯顺序走流程图。
- 动作之间的流转连线用 `relation:"flow"`（与流程图一致），顺序与并发由节点顺序和分叉 / 汇合横杠表达。
