决策树 = 从根问题出发，按条件一层层二分 / 多分，直到叶子给出结论。

- **必须声明 `diagramType:"decision-tree"`**。
- 内部节点（要问的问题 / 判断条件）用**矩形**，叶子（最终结论 / 行动）用**椭圆**。**叶子上不再有出边**（只有内部节点向下分叉）。分支连线**不写 `relation`**（用默认样式），分支含义靠连线标签上的条件（「是 / 否 / 金额 > 5000」）表达。
- 每条出边必须写清该分支的条件（「是」「否」「金额 > 5000」）；同一节点下的条件要互斥且覆盖完整（不要漏掉「其他」）。
- 树是单向的：只能从根往叶子走，不要出现回边或跨层连线。
- 层数控制在 3~4 层；更深就先合并条件。
- 同一层的判断要是同一类问题（别一层问金额、下一层又问金额）。
