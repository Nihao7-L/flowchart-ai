故障树 = 顶事件在上，逐层往下拆解成因，用「与 / 或」逻辑门连接。

- **必须声明 `diagramType:"fault-tree"`**。
- 顶部只有一个**顶事件**（系统不可用 / 订单失败），画成菱形或矩形并注明「顶事件」；往下是中间事件，最底层是基本原因（矩形）。
- 逻辑门用节点表达并在 label 里写门类型：**「与门 AND」/「或门 OR」**。没有门节点类型的，就建一个名为「AND」/「OR」的矩形节点充当门，父事件连到门、门再连到各个子原因。
- 方向一律**自上而下**（父 → 门 → 子），不要反向、不要跨层。
- 父 → 门 → 子的连线**不写 `relation`**（用默认样式），逻辑由门节点 label（AND / OR）表达。
- 或门 = 任一子原因发生即可导致父事件；与门 = 所有子原因同时发生才导致。label 里写清是哪个门。
- 基本原因要拆到可验证（「磁盘写满」），不要停在「系统问题」。
