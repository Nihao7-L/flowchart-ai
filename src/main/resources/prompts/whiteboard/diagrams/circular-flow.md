循环图 = 首尾相接的一圈环节，表示不断重复的过程。

- **必须声明 `diagramType:"circular-flow"`**。
- 环节依次首尾相连成环（计划 → 执行 → 检查 → 改进 → 回到计划），**最后一根回到起点的线是这个图的必要结构，不要省略**。
- 每个环节一个矩形节点，环节数量 3~6 个；少于 3 个不成环、多于 6 个环会挤成一团。
- 连线用 `relation:"flow"`，一律同向（顺时针），不要出现逆行的箭头。
- 每轮循环的输出 / 产物（报告 / 指标）可以从环上引出一个节点，但不要让它打断环；引出节点挂在一侧。
- 与流程图的区别：流程图有终点、循环图没有终点，别在环上画「结束」节点。
