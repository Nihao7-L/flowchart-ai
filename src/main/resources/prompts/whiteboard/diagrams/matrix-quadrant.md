矩阵图 = 两条轴切出四个象限，每个象限放一类内容。

- **必须声明 `diagramType:"matrix-quadrant"`**。
- **每个象限 = 一个 `group`**：象限名写进 group（重要且紧急 / 重要不紧急 / 紧急不重要 / 不紧急不重要；或 SWOT 的优势 / 劣势 / 机会 / 威胁）。内容节点归进各自象限的 group。
- 两个轴的含义写进 `title` 或象限名里（优先级矩阵（紧急度 × 重要度）），**不要只画四个空框**。
- 象限里的条目是并列关系，条目之间**不要连线**（一连就不是矩阵了）。
- 本图型**不使用 `relation`**：象限内条目之间不要连线（矩阵靠分区表达），因此也不需要写 relation 字段。
- 每个象限 2~5 个条目，四个象限的条目数量要大致均衡（一个象限塞十条会压塌版面）。
- 没有坐标轴的图元类型时不要硬画轴线：靠四个 group 分区表达象限即可。
