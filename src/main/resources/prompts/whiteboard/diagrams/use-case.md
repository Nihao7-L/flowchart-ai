用例图 = 系统边界 + 边界外的参与者（人 / 外部系统）+ 边界内的用例。

- **必须声明 `diagramType:"use-case"`**。
- 参与者画成椭圆或矩形并注明角色（用户 / 管理员 / 支付网关），用例画成椭圆，写动宾短语（下单 / 退款 / 导出报表）。
- 参与者与用例之间只有**关联线**（无箭头），不要画成调用箭头。
- 用例之间的关系只有三种：`include`（必做，标签写 «include»）、`extend`（可选分支，写 «extend»）、泛化（子用例继承父用例，用 `relation:"inherit"`）。
- 系统边界用一个 `frame` 把所有用例框进去，框名写系统名；参与者留在框外。
- 不要画成流程图：用例之间没有先后顺序，不要给它们连顺序箭头。
