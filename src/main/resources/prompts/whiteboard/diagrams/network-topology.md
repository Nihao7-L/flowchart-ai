网络拓扑图 = 网络设备（节点）+ 链路（连线），重点是连通关系与区域划分。

- **必须声明 `diagramType:"network-topology"`**。
- 设备节点 label 写「类型 + 名称」（核心交换机 SW1 / 防火墙 FW / 路由器 R1），同类设备用同样的形状（交换机矩形、防火墙菱形、终端椭圆）—— **这些形状是「本工具内部约定」，并非行业图标标准（Cisco / 网络图标体系不这么对应），仅用于区分设备类型，不要当成标准拓扑符号**。
- 链路（连线）上标链路信息（「10G 光纤」「VLAN 100」）；**连线两端都是设备，不要连到区域**。
- 区域（办公区 / DMZ / 机房 / 云上 VPC）用 `group` 表达，同一区域的设备归到同一个 group。
- 链路是无向的连接关系，用 `relation:"dependency"` 或 `"data"`，不要画成调用箭头链（拓扑不是流程）。
- 关键设备要体现出层级：核心 → 汇聚 → 接入，自上而下排；不要把所有设备平铺成一行。
