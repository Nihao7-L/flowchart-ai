用户旅程图 = 用户为达成目标所经历的一串阶段，每个阶段带上行为、触点、情绪与痛点。

- **必须声明 `diagramType:"user-journey"`**。
- 主线是**阶段**：认知 → 考虑 → 购买 → 使用 → 复购，按时间从左到右（或自上而下）单向排列，用 `relation:"flow"` 连成链。
- 每个阶段挂 1~2 个附属节点写关键内容（行为 / 触点 / 痛点），附属节点用 `group` 归到所属阶段，不要另起一条平行链 —— 否则会变成两条互不相干的流程。
- 情绪曲线用一串菱形节点表达并在 label 里写情绪（期待 / 困惑 / 满意），挂在各阶段下方。
- 痛点要写具体（「找不到优惠券入口」），不要写「体验差」。
- 阶段数量 4~6 个；每个阶段只有一个核心动作，别把多个动作塞进同一阶段。
