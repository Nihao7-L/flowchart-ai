时间轴 = 一条主线 + 按时间先后挂在主线上的事件。

- **必须声明 `diagramType:"timeline"`**。
- 每个事件一个节点，label 里「时间 + 事件」写成两行（2019 / 公司成立），时间在上、事件在下。
- 事件之间按时间先后用单向箭头连成一条链（早 → 晚），**不要双向、不要分支成网**。
- 事件链上的箭头**不写 `relation`**（用默认样式），时间先后由连接顺序表达。
- 时期 / 阶段用 `group` 表达（初创期 / 增长期），同一时期的事件归一组。
- 里程碑事件（重要转折点）单独用菱形节点区分于普通事件的矩形。
- 一律单向推进：不要出现从后往前的回指箭头；若某事件引发另一个事件，另起一根带说明的侧链，别把主线搅乱。
