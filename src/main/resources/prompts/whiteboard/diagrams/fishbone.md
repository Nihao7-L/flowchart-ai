鱼骨图 = 右侧一个「问题」+ 左侧若干大类原因，每个大类再细分出具体原因。

- **必须声明 `diagramType:"fishbone"`**。
- 头部（问题）单独一个节点，label 写清问题本身（「登录失败率上升」），它是全图唯一的目的节点。
- 大类原因按方法论分：人 / 机 / 料 / 法 / 环 / 测，或 4M、5Why 等；**每个大类用一个 `group` 命名**，该大类下的具体原因都归进这个 group。
- 具体原因是叶子节点，指向它所属的大类；**叶子不要再往下一级连**（鱼骨图只有「大类 → 具体」两层）。
- 连线方向一律「原因 → 问题」，从外围往头部汇聚，不要反过来。
- 原因 → 问题的连线**不写 `relation`**（用默认样式），方向已经表达因果，不要加 relation。
- 具体原因写成一个可验证的事实（「验证码短信延迟 30s」），不要写「沟通不畅」这种没法验证的抽象词。
