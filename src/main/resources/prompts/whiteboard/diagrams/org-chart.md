组织架构图 = 按汇报关系分层的一棵树，上层管下层。

- **必须声明 `diagramType:"org-chart"`**。
- 顶层只有一个节点（CEO / 总经理 / 负责人），不要出现两个互不相干的根节点。
- 连线方向必须是**上级 → 下级**（从根往下），不要反向、不要在下级之间横向连。
- 同一层的同级部门用 `group` 归到同一个上级名字下，层级就靠 group 体现；层级不同的节点不要混进同一 group。
- 岗位框里写「部门 / 岗位名」，需要时第二行带人名；不要把整段职责说明塞进框里（会撑爆节点、压住别的框）。
- 虚线汇报（虚线汇报 / 矩阵制 / 兼管）用 `relation:"dependency"` 区分于实线的直接汇报。
- 助理、虚线岗这类不占正式层级的角色，单独放侧边，不要插进主层级链里把层数撑乱。
