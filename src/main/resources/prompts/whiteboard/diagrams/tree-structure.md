树形结构图 = 一个根 + 逐层展开的父子层级，用来表达目录、分类、菜单、指标体系。

- **必须声明 `diagramType:"tree-structure"`**。
- 根在上、叶子在下；父节点与子节点之间一条无标签的连线（父子关系由结构本身表达，不需要在连线上写「包含」）。这条父子连线**不写 `relation`**（用默认样式），层级由结构本身表达。
- **每层用 `group` 标出层名**（一级分类 / 二级分类），同层节点归到同一 group，层级就不会混。
- 叶子节点写具体项（登录日志 / 订单表 / 用户画像），非叶子写类名（用户域）。
- 兄弟节点之间不要连线；一个子节点只挂一个父节点。
- 深度控制在 3~4 层；同一层的兄弟数控制在 2~6 个，多了就先归大类。
