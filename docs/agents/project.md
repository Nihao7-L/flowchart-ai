## 一、一句话定位

ChartFlow：基于 Spring Boot + 大语言模型（LLM，即 ChatGPT 这类模型）的 AI 图表生成器。
链路：用户自然语言描述 → 后端组装 Prompt 调 LLM → 产出结构化图 JSON → 校验 → 渲染流程图 / 思维导图 / 架构图。

标准：**求职核心项目，按真实企业级产品要求**——不按"面试 demo"标准放过自己。
