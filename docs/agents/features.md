## 功能完成的定义

同时满足四条才算"完成"，缺一条就是"部分"：

1. 代码进了 `reframing` 分支并提交
2. `run-verify.ps1` 绿（并把输出记进 `activeLog.md`）
3. 本篇状态列已更新，路线图对应项已勾
4. 验收口径（写在对应 exec-plan 里）逐条通过
