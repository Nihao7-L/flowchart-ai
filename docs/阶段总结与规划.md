# AI 流程图生成器（FlowAI）— 阶段总结与规划

## 一、第一版 Demo 总结

### 1.1 定位

第一版只做一件事：**验证"自然语言 → 流程图"这条路能跑通**。

不是产品，不是正式版，就是一个 Demo——证明技术链路可行，后面才有继续投入的意义。

### 1.2 Demo 做了什么

```
用户输入文字 → Gemini AI 生成 JSON → PlantUML 渲染 SVG → 浏览器展示 + 下载
```

就这一条线，端到端跑通。

| 模块 | 做了什么 | 技术选型 |
|------|---------|---------|
| 后端 | 接收文字 → 拼 Prompt → 调 AI → 解析 JSON → 转 PlantUML → 渲染 SVG | Spring Boot 3.2 + Java 17 |
| AI | 文字 → 结构化 JSON | Gemini 2.0 Flash |
| 渲染 | PlantUML 源码 → SVG 图片 | PlantUML Java API |
| 前端 | 输入框 + 生成按钮 + SVG 展示 + 下载 | 原生 HTML/CSS/JS |

### 1.3 Demo 已知局限

| 问题 | 原因 |
|------|------|
| 只有 SVG 格式，没有 PNG | Demo 阶段没做 |
| AI 偶尔生成循环边导致渲染异常 | ✅ 已在 Prompt 加防循环规则，且 DiagramService 兜底 |
| 前端 SVG 不能缩放/拖拽 | 没做交互 |
| 没有用户系统、没有历史记录 | Demo 不需要 |
| 只有流程图一种类型 | Demo 只验证流程图 |

### 1.4 代码结构

```
src/main/java/io/github/nihaoljx/flowchart/
├── FlowchartApplication.java          # 启动入口
├── client/
│   └── AiApiClient.java               # Gemini API 调用
├── controller/

├── model/
│   ├── FlowchartData.java             # 数据模型

    └── DiagramService.java             # PlantUML 转换 + SVG 渲染
```

### ✅ 19. PNG 格式输出

> **目标**：支持 SVG 和 PNG 两种格式，用户可选择下载。

**为什么做**：SVG 是矢量图，适合网页；但很多人需要 PNG 往文档里贴，Office 不支持直接插入 SVG。

**怎么做**：
- `DiagramService` 加 `renderToPng()` 方法（PlantUML `FileFormat.PNG`）
- Controller 加 `format` 参数（`svg` / `png`），默认 `svg`
- 前端加格式切换按钮
- PNG 下载 MIME type 改 `image/png`

**验收**：选择 PNG 能下载到图片，选择 SVG 不受影响。

---

### ✅ 20. Prompt 调优 v2

> **目标**：让 AI 输出更稳定，从"偶尔出问题"到"基本不出问题"。

**为什么做**：Demo 阶段 AI 偶尔生成循环边（如"否"分支指回已访问的节点），导致渲染出悬空线。

**怎么做**：
- Prompt 加防循环规则：
  ```
  - 流程必须是单向的，从 start 到 end，不要循环
  - 除非用户明确提到"循环""重复""回到某一步"，否则不要产生回溯边
  - decision 的两条分支最终都应到达 end
  ```
- 连续 10 次不同输入测试，确保 JSON 均能被解析
- 测试 5 个典型场景：登录流程、审批流程、订单流程、带循环的流程、短描述

**验收**：连续 10 次输入，0 次渲染异常。

### ✅ 21. 前端交互升级

> **目标**：SVG 可缩放可拖拽，加主题/配色切换，UI 整体升级。

**完成内容**：
- 前端框架从原生 JS 升级为 Vue 3（CDN 版，无需 npm 构建）
- 文件拆分：`index.html`（结构）+ `style.css`（样式）+ `app.js`（逻辑）
- 布局改为 WorkBuddy 式：左侧边栏 + 右侧工作区（画布在上、输入框在下）
- SVG 滚轮缩放 + 鼠标拖拽平移 + 缩放控制按钮（放大/缩小/重置/百分比）
- 明暗主题切换（CSS 变量方案，`data-theme` 属性 + `localStorage` 持久化）
- 占位接口：思维导图/架构图/历史记录/设置点击弹出"开发中"提示
- 模型选择下拉框（UI 占位，当前仅 Kimi 可用）

**Vue 3 核心用法**：`ref()` 响应式、`v-model` 双向绑定、`v-if/v-html` 条件渲染、`:style` 动态样式、`computed` 计算属性

**验收**：SVG 能放大缩小拖拽，切换主题后整体配色变化，布局正常显示。

### ✅ 22. 多图表类型

> **目标**：除了流程图，支持生成思维导图和架构图。

**为什么做**：用户描述的不一定都是流程。比如"系统架构"应该画架构图，"知识梳理"应该画思维导图。

**怎么做**：
- 前端加图表类型选择（流程图 / 思维导图 / 架构图）
- 每种类型对应一套 Prompt 模板 + 一套 PlantUML 语法映射
- `DiagramService` 加 `buildMindMap()` 和 `buildArchitecture()` 方法
- 后端按类型路由到不同的 Prompt + 转换逻辑

**验收**：选择"思维导图"输入"电商系统组成"，能生成树状思维导图。

### ✅ 23. 错误处理完善

> **目标**：6 个边界场景全覆盖，用户怎么折腾都不白屏。

**6 个场景全部完成**：

| 场景 | 状态 | 实现方式 |
|------|------|---------|
| 空输入 | ✅ | 前端 trim + 后端 isBlank |
| 超长输入（>2000字） | ✅ | 前端 + 后端拦截 |
| AI 返回格式异常 | ✅ | catch + 脱敏 + 原始响应打印（排查用） |
| 请求超时 | ✅ | 后端 HttpRequest 60s + 前端 AbortController 70s（分层超时） |
| API Key 未配置 | ✅ | `isConfigured()` 在 `/api/generate` 入口拦截，返回 503 |
| 嵌套判断（if 套 if） | ✅ | end 节点提前处理不走 visited 检查，多分支汇聚 end 不再误报循环 |

**验收**：6 个场景均有明确反馈，无白屏。嵌套 if 场景测试通过。
