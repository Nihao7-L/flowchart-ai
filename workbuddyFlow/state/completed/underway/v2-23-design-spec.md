## 用户确认的布局方案（2026-09-16 截图 + 反馈）

### 三栏布局

```
┌──────────────┬────────────────────┬──────────────┐
│   左导航栏     │    中间画布区域      │   右侧聊天栏  │
│   (240px)     │   (flex: 1)        │   (340px)    │
│               │                    │              │
│  新建对话      │   Excalidraw 画布   │  聊天消息列表  │

└──────────────┴────────────────────┴──────────────┘
```

### 布局说明

| 区域 | 位置 | 宽度 | 内容 |
|---|---|---|---|
| **左导航栏** | 左侧 | 240px 固定 | 新建对话（顶部）、Library（中部）、历史对话列表（中下部）、主题切换（底部） |
| **中间画布** | 居中 | flex: 1（自适应） | Excalidraw 白板 + 自带工具栏 + 缩放控制，完全继承 PoC 原型 |
| **右侧聊天栏** | 右侧 | 340px 固定 | 聊天消息列表（user/agent/tool/error 样式）、聊天输入框 + 发送按钮 |

### 组件规范

#### 左导航栏（240px）

| 组件 | 位置 | 说明 |
|---|---|---|
| 新建对话 | 顶部 | 蓝色按钮，点击清空当前对话和画布，开始新对话 |
| Library | 中部 | 按钮，点击弹出侧边面板（Excalidraw 原生 Library 面板：标题 + 固定/关闭按钮 + 空状态提示 + Browse libraries 按钮） |
| 历史对话列表 | 中下部 | 可折叠列表，显示之前的对话记录标题 |
| 主题切换 | 底部 | 黑白切换按钮，切换深色/浅色主题 |

#### 中间画布（flex: 1）

完全继承 PoC 原型 `excalidraw_collab.html` 的结构：

| 组件 | 说明 | 来源 |
|---|---|---|
| Excalidraw 白板 | 核心画布，支持拖拽/手绘/选中/缩放 | PoC `#root` |
| 工具栏 | Excalidraw 自带（矩形/椭圆/箭头/文字等） | PoC 内置 |
| 缩放控制 | 底部居中，100% 缩放显示 | PoC 内置 |

#### 右侧聊天栏（340px）

| 组件 | 说明 | 来源 |
|---|---|---|
| 聊天消息列表 | 滚动区域，显示 user/agent/tool/error 消息 | PoC `#log` |
| 示例按钮组 | 快捷命令按钮（可选，v2-24a 先不做） | PoC `#examples` |
| 聊天输入框 | 底部，用户输入文字 | PoC `#cmd` |
| 发送按钮 | 输入框右侧 | PoC `send()` |

### 交互规范

| 场景 | 行为 |
|---|---|
| 用户在画布拖拽 | 直接操作 Excalidraw 元素（人类编辑通道） |
| 用户在聊天框输入 | 发送到后端 `/api/chat`，SSE 推送结果，画布更新（AI 编辑通道） |
| 用户拖拽节点后 | 前端调 `PUT /api/model/canvas` 回写坐标（M6b①，已于 S1 提前交付：v2-34） |
| 点击新建对话 | 清空画布和对话历史，重置为初始状态 |
| 主题切换 | 切换深色/浅色主题，画布背景同步变化 |

### 不变项（从 PoC 原型继承）

- Excalidraw 白板的全部交互能力（拖拽、手绘、选中、缩放）
- 双通道协作：人类拖拽 + AI 聊天命令都改同一份数据
- 初始渲染无 NaN 视口
- 选中不丢绘制能力
- 布局算法（`layout()` 函数，层级布局）
- 元素渲染（`buildSkeletons()` + `convertToExcalidrawElements()`）
- 位置同步（`syncPositions()` + `onChange`）
- 视图适配（`fitView()`，手动算包围盒避免 NaN）

### 与 PoC 原型的差异

| 项目 | PoC 原型 | v2-23 设计稿 |
|---|---|---|
| 布局 | 左聊天 + 右画布（两栏） | 左导航 + 中画布 + 右聊天（三栏） |
| 聊天位置 | 左侧 | 右侧 |
| 导航功能 | 无 | 左侧新增新建对话/Library/历史/主题切换 |
| 背景色 | `#f0f0ee` 浅米 | `#FFFFFF` 纯白 |
| 命令解析 | 本地 `interpret()` 函数 | 改为调后端 `/api/chat`（SSE） |

## 验收口径

## 决策变更（2026-09-16，用户提出并拍板）

| 项 | 原设计稿 | 变更后 | 原因 |
|---|---|---|---|
| 主题切换（左栏底部按钮） | 保留，切换深色/浅色 | **移除**，全站固定浅色（白底） | 用户 09-16 选「干脆不要深色主题」；与「背景都是白色」的原始要求一致 |
