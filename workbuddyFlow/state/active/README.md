# active/ — 当前唯一活跃项

本目录放**最活跃的那个计划**，它**从 `../underway/` 中来**（underway 里的进行中计划，被提升为当前焦点）。

- 遵循**状态机规则：同一时刻只保留 1 个文件**（当前活跃计划）。
- 进入活跃态：将 underway 里的某个进行中计划移入此处。
- 离开活跃态：完成即移出——收尾移 `../state/completed/`，或退回 `../underway/` 继续。
- **空目录 = 当前无活跃项**，为合法状态。
- 与 `../state/activeLog/`（追加式历史）区分：active 是"现在在做什么"的单点快照，activeLog 是"做过什么"的时间线。
