## 一、项目名 + 一句话定位

**ChartFlow**：基于 Spring Boot + 大语言模型（LLM，即 ChatGPT 这类模型）的 AI 图表生成器，把自然语言描述变成流程图 / 思维导图 / 架构图，并支持"人类手绘 + AI 聊天"双通道协作编辑。
