## 目标
prompt 内容按 **Role / Task / Context / Format** 重排（关键约束固定首尾，治 Lost in the Middle）；加 1~2 个 canonical few-shot；
做**意图路由模板**（画新图 / 改图 / 问答 三岔，稳定"改图 vs 另画"判定）；落**原生结构化输出**；
