# 计划模板（TEMPLATE）

> 用法：每个核心功能 / 有影响力的改动，复制本模板到 `plans/masterPlan/mN-<模块>.md`，顶部状态行置「待审」，交人确认后才动码。
> 这是 workflow 第 ② 拍的硬性要求：让评审者审 **Plan**，而非审 diff。
> 六段（目标 / 边界 / 分层边界 / 前置 / 步骤 / 验收口径 / 覆盖测试数据）缺一不可，否则视为未完成。

## 元信息
- 任务编号：vX-N
- 状态：待审 | 进行中 | 阻塞 | 完成
- 关联模块：见 `plans/masterPlan/` 下对应模块计划（M0~M7）
- 创建：YYYY-MM-DD + 作者
