# masterPlan/ — 模块总计划

一个核心模块一个文件 `mN-<模块>.md`（如 `m1-generation.md`）。

- **执行顺序见 `roadmap.md`（S0~S6）**：本目录的 `mN-` 与 `v2-N` 是**身份**（改哪些包 / 哪个任务），`roadmap.md` 里的 `S` 才是**时间**（先做哪个阶段）。**要调先后只改 S，不动编号**。

- **一个模块内含多个 v2-N 子计划**：每个模块文件是"总计划"，里面按 `v2-3` / `v2-4` / … 拆成多条子计划，每条各自带状态行（`规划中 | 进行中 | 阻塞 | 完成`）。
- 总计划是稳定基线，**不要重写**；子计划的推进只改它自己的状态行。
- 当某个 v2-N 子计划进入"进行中"，它的工作台计划放进 `../underway/`（见 `underway/README.md`）。
- 模块**整体完成**后：文件移入 `../state/completed/masterPlan/`（保留原始内容，只加一行完成结论）。已归档：`m0-harness.md`（M0 工程底座，2026-09-14 移入）。
- 模板见 `TEMP.md`（六段：目标 / 边界 / 分层边界 / 前置 / 步骤 / 验收口径 / 覆盖测试数据）。
